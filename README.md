# Sara-El-Boukili-Portfolio
Passionnée par l'amélioration continue, je maîtrise des outils d'analyse statistique des données, traitement et pilotage des KPI en temps réel. J'applique les méthodes Lean 6 Sigma  DMAIC, VSM, 5S, Ishikawa  pour structurer l'analyse des processus, identifier les causes racines et proposer des actions d'amélioration mesurables.
